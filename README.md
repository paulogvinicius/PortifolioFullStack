## 🚀 Sobre o Projeto

Este é o meu portfólio pessoal e profissional, desenvolvido para centralizar meus projetos, conhecimentos e trajetória no desenvolvimento de software. O design foi construído sob uma estética moderna, limpa e responsiva, destacando uma interface inspirada em editores de código (mockup IDE) para apresentar minhas informações de forma criativa.

* **Foco Principal:** Lógica de programação, arquitetura de sistemas e gerenciamento de bancos de dados.
* **Diferenciais Visuais:** Efeitos de digitação dinâmica (*typing effect*), animações fluidas com *ScrollReveal* e organização em alta performance com CSS Grid e Flexbox.

---

## 🛠 Tecnologias & Ferramentas

O ecossistema do portfólio foi construído utilizando tecnologias web nativas para garantir máxima velocidade de carregamento e fidelidade de design:

* **Front-end:** HTML5, CSS3 (Variáveis nativas, Grid e Flexbox)
* **Interatividade:** JavaScript (ES6+)
* **Bibliotecas:** [ScrollReveal](https://scrollrevealjs.org/) (para animações de scroll controladas)
* **Fontes:** DM Sans & Gemunu Libre via Google Fonts
